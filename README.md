# 每日费用

本仓库提供每日费用的 Windows 便携版、安卓安装包和正式更新。

[下载最新正式版](https://github.com/qq29032979/daily-expense/releases/latest)

- Windows 10/11 x64 选择 **DailyExpense-win-x64.zip**。完整解压后打开「每日费用.exe」。
- Android 8.0 及以上选择 **DailyExpense-android.apk**。已有旧版时可直接覆盖安装。

软件打开或回到前台时会检查更新。也可以在「版本介绍」中手动检查。费用和票据保存在本机，需要传送时再执行设备同步。
